# Cloudn 1.2 · OneDrive 与 Google 云端硬盘「我的网盘」

## 新增

- **OneDrive「我的网盘」**：用微软账号登录（个人版、工作或学校账号都可以），浏览、下载、上传（大文件分片）、新建文件夹、重命名、移动、删除、查看容量。登录后，只分享给你的 OneDrive 链接也能直接打开。
- **Google 云端硬盘「我的网盘」**：用 Google 账号登录，浏览、下载（Google 文档自动导出为 Word / Excel / PowerPoint）、上传、新建、重命名、移动、删除、查看容量；公开分享里的文件可以复制到自己的云端硬盘。
- **分享设置**：在这两个网盘里长按文件选「分享设置…」——
  - OneDrive：谁能访问（知道链接的任何人 / 仅组织内）、仅查看或可编辑、有效期、密码；
  - Google：知道链接的任何人可查看 / 可编辑；
  - 都能看到已有的分享链接并一键取消。
- **隐私政策**：新增 [PRIVACY.md](https://github.com/mengangs/Cloudn/blob/main/PRIVACY.md)，「设置 › 关于」里可以打开。

## 说明

- 登录走微软 / Google 的官方登录页，Cloudn 只拿到访问文件的授权，令牌只保存在本机钥匙串里，可随时在账号设置里撤销。
- Google 登录时会看到「Google 尚未验证此应用」，点「高级 › 继续」即可。
- OneDrive 个人版设有效期、密码需要 Microsoft 365 订阅。

## 安装

下载下方附件里的 `Cloudn-v1.2.0.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
