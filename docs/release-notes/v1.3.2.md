# Cloudn 1.3.2

## 改进

- **视频播放顶栏浮在画面上**：不再把画面往下挤；轻点画面和系统播放控件一起显示 / 隐藏，播放中 3 秒后自动隐藏，横屏时画面铺满。
- **网盘文件点开就能预览**：「我的网盘」里点视频、音频、图片直接在线播放 / 查看，文本在线阅读，PDF、Word、Excel、PPT 等文档载入后用系统预览打开；右侧的下载键照常下载，长按菜单也有「预览」「下载」。分享里的文档也新增「预览」。
  - MKV、AVI 等系统播放器放不了的视频、压缩包等仍然直接下载。

## 安装

下载下方附件里的 `Cloudn-v1.3.2.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
