# Cloudn 1.1 · 新增 3 个网盘

## 新增

- **Google 云端硬盘**（免登录）：公开分享的文件和文件夹都能浏览、下载，文件夹可整批下载；Google 文档 / 表格 / 幻灯片自动导出为 Word / Excel / PowerPoint。
- **OneDrive**（免登录）：个人版（1drv.ms）和工作或学校版（SharePoint）的分享都支持，下载支持断点续传；设了密码的分享填上密码即可。
- **阿里云盘**：免登录浏览分享（支持提取码）；在「我的」页登录后可以下载、转存，并管理自己的阿里云盘——资源库 / 备份盘浏览、下载、新建文件夹、重命名、移动、删除（进回收站）、创建分享、上传（支持秒传）。

## 改进

- **主页 / 合集解析显示实时进度**：解析抖音、快手作者主页，YouTube 播放列表，SoundCloud 歌单时，输入框上方显示「已获取 N 个」（有总数时显示「N / 总数」）。嫌慢可以点「停止」，用已拿到的部分直接出结果。
- 每日在线检查加入 Google 云端硬盘、OneDrive、阿里云盘，接口一变当天就能发现。

## 安装

1. 下载下方附件里的 `Cloudn-v1.1.0.ipa`，用 AltStore、SideStore、Sideloadly、TrollStore 等工具签名安装（需要 iOS 17 及以上）。
2. 已安装 1.0 的用户可以在「设置 › 检查更新」里直接获取。

> IPA 未签名，需要自行签名后安装。`SHA256SUMS.txt` 可用于校验文件完整性。

## 说明

- 阿里云盘的「我的网盘」需要设备签名，首次打开时会多花一两秒。
- Google 云端硬盘、OneDrive 暂不支持登录自己的账号，只支持分享链接。
