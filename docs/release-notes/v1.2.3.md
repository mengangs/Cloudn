# Cloudn 1.2.3

## 改进

- **全新的「排序与显示」页**：点「我的」页左上角的排序按钮、网盘 / 视频平台末尾的「更多」，或长按卡片菜单里的「排序与显示…」打开。
  - 网盘 / 视频平台分栏切换；拖动右侧把手排序，用的是系统列表的拖动，拖到页面边缘会自动滚动，长列表也能一路拖到顶部；
  - 每个平台一个开关决定是否在「我的」页显示，并标出登录状态；右上角菜单可一键「全部显示」「只显示已登录」「恢复默认顺序」。
- **「我的」页不再折叠**：按你的选择直接显示，没显示的平台收在末尾的「更多网盘」「更多视频平台」里。
- **「我的」页打开更稳**：网盘容量先显示上次的缓存，后台取到新数据后原地替换（取失败保留旧值）；启动时同步读取账号，不再先闪一下「未登录」再出现。
- 设置里原来的「『我的』页显示的网盘」并入「排序与显示」。

## 安装

下载下方附件里的 `Cloudn-v1.2.3.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
