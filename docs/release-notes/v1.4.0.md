# Cloudn 1.4.0

这一版主要打磨界面和使用体验，解析、下载、登录的功能本身没有变化。

## 新增

- **iPad 侧栏**（iOS 18 及以上）：三个标签页可以展开成侧栏；iPhone 与 iOS 17 保持原样。
- **拖放**：把链接、文字或 .torrent 文件拖进 Cloudn 即可解析，多个链接走批量解析。
- **保存更直接**：下载完成的任务行尾直接是「保存」（图片、视频存相册，其他文件存到「文件」）；预览页顶栏加「保存到相册」。
- **转存时新建文件夹**：选保存位置时右上角可以直接新建文件夹（平台支持时）。
- **失败筛选**：下载页有失败任务时多一个「失败」筛选。

## 改进

- **首次使用**：解析页空状态加使用引导，输入框旁加粘贴按钮，一键粘贴并解析；「我的」页说明不登录也能用、登录后能多做什么。
- **直链失效自动换链**：HTTP 403 / 404 / 410 / 412 这类直链失效的任务，点重试会重新获取直链再继续；网络错误仍按原地址重试。
- **出错时给出下一步**：视频需要登录时首选「去登录」；分享已失效时给「复制链接」「用浏览器打开」；未登录不能下载的网盘主按钮改为「登录后下载」，点按就地登录；GitHub 需要 Token 时直接给填写入口。
- **网页嗅探**：结果里最长的一条标「推荐」，每行可直接下载并显示进度，面板不再自动收起；录制按钮撑满整行。
- **批量解析**：顶部加总进度条，失败条目可改用网页嗅探，完成后可直接去下载页。
- **分享扩展**：修复从其他应用分享到 Cloudn 时一闪白页、不跳转的问题；跳不过去时自动复制链接并给「打开 Cloudn」。
- **实时活动**：点锁屏或灵动岛直接打开下载页；显示剩余时间；进度颜色跟随主题色。
- **轻提示**不再盖住页面底部的主按钮。
- **触感**：解析成功、分享打开、任务下完时有轻微震动反馈；开启「减弱动态效果」后按钮不再缩放。

## 显示与无障碍

- 最大辅助字号下，操作条、提示卡、下载卡片、容量条、设置项改为上下排列，不再挤压或截断。
- iPad 上各页内容收窄到适合阅读的宽度并居中。
- 提高选择圆圈、进度条底轨、暂停进度和浅色主题色的对比度（如赭石在浅色下自动压暗）；系统弹窗按钮跟随主题色。
- 小按钮、文字按钮、筛选胶囊的点按区域补到 44pt；图集格子、保存按钮支持读屏直接操作。
- 数字统一用系统字体与等宽数字，等宽字体只用于链接、提取码等；文案统一为「加入下载 / 保存到相册 / 保存到「文件」/ 转存」。

## 安装

下载下方附件里的 `Cloudn-v1.4.0.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
