# Cloudn 1.3.1

## 改进

- **图片预览可以左右滑动**：图文 / 图集里点开任意一张，左右滑动看其他图片，顶部显示「3 / 12」；每张都能双指缩放、双击放大，轻点隐藏顶栏。
- **视频可以横屏**：在线预览和已下载的视频顶部新增横屏按钮，锁定了竖屏也能切换，关闭后自动转回竖屏。
- **Dropbox 授权登录**：点「登录」通过 Dropbox 官方页面授权，不用再手动粘贴令牌。
- **天翼云盘新设备短信验证**：账号密码登录遇到「验证新设备」时，自动切到短信验证码并发送到绑定手机，填入验证码即可完成登录。

## 修复

- **B 站专栏 / 图文动态只解析出一部分**：现在取完整正文和文中全部图片（按原文顺序，原图画质）；也支持 bilibili.com/read/cv 专栏链接。
- **图片预览下滑关闭时画面抖动**：拖动跟手更稳。

## 安装

下载下方附件里的 `Cloudn-v1.3.1.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
