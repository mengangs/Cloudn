# Cloudn 1.1.1

## 修复与改进

- **阿里云盘「我的网盘」**：之前只能看到备份盘里的文件，「来自分享」等资源库里的文件夹看不到。现在和阿里云盘 App 一样：根目录是资源库的内容，顶部是「备份文件」「相册」两个系统文件夹。修改时间改为本地时间显示。
- **抖音作者主页**：未登录时抖音网页版通常只给第一页（约 18 个）作品。现在可以在「我的」页登录抖音，登录后获取全部作品（最多 300 个）；未登录时结果页会说明原因。作者主页的列表标题改为「作品」。
- **检查更新**：更新说明按格式显示（标题、列表、链接），顶部显示版本变化、发布日期和安装包大小；「下载更新」放在底部醒目位置；新增「用侧载工具直接安装」，可把安装包直接交给 TrollStore、SideStore、AltStore。
- **解析页**：支持平台的图标按每行 10 个对齐排列。

## 安装

下载下方附件里的 `Cloudn-v1.1.1.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
