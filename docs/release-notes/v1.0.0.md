# Cloudn 1.0 · 第一个正式版

**粘贴一个链接，剩下的交给它。** 网盘分享、短视频、网页视频、GitHub、磁力链接，在一个 App 里解析、预览、高速下载。所有解析都在你的手机上完成，没有 Cloudn 服务器，不收集任何数据。

## 亮点

- **10 个网盘**：夸克、UC、百度、迅雷、115、123、139、光鸭、蓝奏云、蓝奏云优享版。可以浏览分享、下载文件或整个文件夹，也能转存到自己的网盘、管理我的网盘、上传（支持秒传）。
- **近 50 个视频与图集平台**：抖音、快手、小红书、哔哩哔哩、微博、视频号、YouTube、X、TikTok、Instagram 等。视频去水印、图集取原图，实况照片可以直接存成相册里的 Live Photo。
- **画质由你挑**：每个清晰度都列出大小和分辨率，默认选最高；抖音支持上传者的「原画」。
- **网页嗅探与录制**：专门解析不了的网站，用内置浏览器抓取正在播放的视频；只有 blob 流的网页可以边播边录。
- **为大文件而做的下载器**：多连接分片、断点续传、直链过期自动换链。切到后台或锁屏后由系统接着下，按段保存进度；锁屏和灵动岛显示实时进度。
- **格式自动处理**：m3u8 / TS 转成 MP4，分离的音视频无损合成；MKV 打开就能播，不重新编码。
- **批量**：一次粘贴多条链接，播放列表、合集、多 P、抖音 / 快手作者主页都能整批加入下载。
- **更多**：GitHub 仓库与 Release、磁力 / BT、字幕存成 SRT、分享扩展、快捷指令唤起、多账号轮换、自定义主题色、深色模式。

## 安装

1. 下载下方附件里的 `Cloudn-v1.0.0.ipa`。
2. 用 AltStore、SideStore、Sideloadly、TrollStore 或你习惯的签名工具安装（需要 iOS 17 及以上）。
3. 以后在「设置 › 检查更新」里就能收到新版本。

> IPA 未签名，需要自行签名后安装。`SHA256SUMS.txt` 可用于校验文件完整性。

## 使用提示

- **登录**：百度、迅雷、115（大文件）等网盘要登录后才能下载。Cloudn 会把文件临时转存到你的网盘取直链，取完立即删除。
- **夸克 / UC 中文口令**：口令只能交给第三方「星海」服务还原，首次使用前会征得你的同意，可在「设置 › 解析」中关闭。这是 Cloudn 唯一用到第三方服务的地方。
- **海外平台**：需要能访问对应网站的网络。Instagram 会拒绝部分 VPN 节点（返回空白页），遇到时请换一个节点。
- **签名方式**：部分企业证书 / 重签安装下，系统不允许 App 直接访问外部文件夹，「完成后保存到」选文件夹时点「打开」会没有反应。这时可以在下载页点「选择」，勾选文件后用「存储到「文件」」导出。
- **后台限制**：m3u8 与磁力下载需要 App 留在前台。普通文件可以在后台继续下载。
