# Cloudn 1.2.4

一次全面的检查与打磨：修复问题、提升稳定性和流畅度，并精简各处提示文案。

## 稳定性

- **登录续期更可靠**：阿里云盘、迅雷、光鸭、Google、OneDrive 同时发起多个请求时只续期一次、共用结果，不再被误报「登录已失效」；阿里云盘长时间使用后下载不再因令牌过期失败；登录校验后保存的凭据不会被提前用掉。
- **Google 云端硬盘**：上传按服务器实际收到的位置续传，中断时不再出错；文件夹多于 1000 个时不再漏列；常见错误都有中文说明。
- **OneDrive**：用自己账号浏览分享太久不再出现「分享已失效」的误报；常见错误都有中文说明。
- **下载**：不支持分段的下载中途断开时会自动续传，不再把不完整的文件当成完成；后台下载时进度刷新更省电。
- **上传**：不支持上传的平台不再卡住队列；上传完成合并为一条提示。
- **实时活动**：在锁屏划掉后不再出现失效的进度；磁力查找重新开始时不再显示上一次的状态。

## 体验

- 「我的」页去掉左上角的排序按钮，排序与显示从「更多网盘 / 更多视频平台」或设置里进入。
- 分享浏览：多选时「全选」在搜索后也正确；下载整个文件夹后再进入，文件顺序不再错乱。
- 磁力文件很多时列表更流畅。
- 应用内复制文本、文件名后，回到解析页不再被误提示「剪贴板里有链接」。
- 我的网盘：新建 / 重命名时名称为空不能确定；返回上级不再重复读取容量。
- 网络错误改为简短中文，例如「网络请求失败：请求超时」。
- 全面精简设置、登录、解析、嗅探、磁力等页面的说明与提示文字。

## 安装

下载下方附件里的 `Cloudn-v1.2.4.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
