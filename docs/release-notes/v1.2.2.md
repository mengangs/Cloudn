# Cloudn 1.2.2

## 新功能

- **「我的」页可以自己排了**：点左上角「排序」，或长按任意网盘卡片 / 视频平台菜单里的「排序与显示…」进入编辑：
  - **按住拖动**网盘卡片或视频平台调整顺序，其余项目跟手让位，松手后归位；
  - **点眼睛**设置收起时显示哪些平台（展开后仍会列出全部）；之后新登录的平台会自动加入显示。
  - 点「完成」退出，顺序与显示设置会记住。

## 修复

- **Google 云端硬盘取消分享报错**：放在已公开文件夹里的文件，会继承文件夹的「知道链接的任何人」，Google 不允许单个文件去掉继承来的分享。现在「已有的分享」会标出「来自上级文件夹『X』」，取消时会提示并直接在那个文件夹上取消（该文件夹里的文件都不再公开）。转存本身不会给文件加公开分享。

## 安装

下载下方附件里的 `Cloudn-v1.2.2.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
