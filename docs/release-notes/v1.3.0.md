# Cloudn 1.3.0

## 新增网盘

- **PikPak**：账号密码登录；分享浏览与下载、转存、我的网盘管理、上传、离线下载。
- **天翼云盘**：账号密码或网页登录；分享免登录浏览，登录后下载、转存、管理我的网盘、上传。
- **WebDAV**：连接坚果云、群晖 / 威联通等 NAS、OpenList / Alist 的 /dav，像网盘一样浏览、下载、上传和管理（「我的」页 › 更多网盘 › WebDAV › 连接服务器）。
- **Dropbox**：公开分享免登录下载（文件夹打包为 zip）；粘贴访问令牌后可管理自己的 Dropbox。
- **城通网盘**：分享免登录浏览与下载。

新网盘默认不显示，在「我的」页末尾的「更多网盘」里打开即可。

## 离线下载（磁链 / 网址存到网盘）

迅雷、115、123、光鸭、百度、夸克、PikPak 登录后，可以让网盘服务器去下载磁力链接或网址，直接存进你的网盘，不用等节点、不占手机流量：

- 磁力链接页新增「离线到网盘」：选网盘和保存位置即可提交，可一次粘贴多条。
- 「我的网盘」右上角菜单新增「离线下载」：查看任务进度（自动刷新），左滑删除记录。

各家对免费账号的离线次数、空间有限制；百度的磁力能否成功取决于其服务器上是否有资源。

## 说明

这些平台的接口在开发环境中无法实际连通，均按开源项目的实现移植并通过单元测试，个别平台可能需要根据真机反馈再调整。

## 安装

下载下方附件里的 `Cloudn-v1.3.0.ipa`，自行签名后安装（需要 iOS 17 及以上）；已安装的用户可在「设置 › 检查更新」里获取。
