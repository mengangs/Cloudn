# Cloudn

**粘贴分享链接，浏览并高速下载 —— SwiftUI 原生 iOS 网盘 / 短视频解析下载应用**

</div>

---

Cloudn 是一款个人独立开发的 iOS 应用：粘贴网盘分享链接即可浏览分享内容、直接下载文件；粘贴短视频链接即可解析无水印视频与图集。

## 界面

「纸与陶土」：暖白纸色底、细线卡片、陶土色强调，标题用内置的思源宋体，深色模式是暖炭灰而不是纯黑。三个标签页——**解析 / 下载 / 我的**。

- 输入框停在底部、单手够得着，随键盘上移；识别出的平台与提取码就地显示、可直接改；剪贴板用系统粘贴控件，同一内容只提示一次
- 分享页每个文件行尾就是它的下载状态：下载键 → 进度环（点按暂停 / 继续）→ 对勾；多选时沿左侧上下拖动可连续勾选；「下载全部」自动跳过已下载的文件
- 下载页顶部是总速度、说成人话的剩余时间和最近几十秒的速度曲线
- 应用内图标为统一的线性图标集；平台图标可在「设置 › 外观」里选线性（默认）或实心

## 功能

- **网盘分享解析**：夸克网盘、UC 网盘、百度网盘、迅雷网盘、115 网盘、123 云盘、139 网盘、光鸭云盘、蓝奏云、蓝奏云优享版，自动识别链接里的提取码（迅雷中文口令也能直接粘贴解析），支持多级目录浏览、多选、整个文件夹下载（保留目录结构）
- **游客下载**：蓝奏云 / 蓝奏云优享版 / 光鸭云盘（公开分享） / UC 未登录即可下载，夸克（约 50MB 以内）与 115（小文件）也可直接下载；登录夸克后不限大小，直链失败时自动回退「临时转存后取链」并在下载完成后清理
- **登录后下载**：百度、迅雷借助临时转存取直链、取完即删；115 大文件转存后走电脑端通道取链，下载完成后自动清理；123、139 登录后直接取分享直链。未登录时这些网盘也能浏览分享内容
- **短视频 / 图集解析**：抖音、小红书（需登录，图集自动换去水印原图）、快手、微博（含 Live 图、动图、转发）、AcFun、Pixiv（登录后可解析受限作品）、哔哩哔哩（视频与动态 / 图文；登录后 1080P+，DASH 音视频下载后用 AVFoundation 无损合轨）、今日头条、百度贴吧、微信公众号、豆瓣、酷安、皮皮虾、最右、知乎（需登录）、X（Twitter）、TikTok、Instagram、Threads
- **高速下载**：Range 多连接分片并发（空闲连接自动接手剩余最多的分片，明显变慢的连接自动重连）、断点续传（任务表与分片进度持久化，重启后可继续）；切到后台或锁屏后，普通文件剩余分片交给系统后台下载会话继续下载，完成后发通知、m3u8（含 AES-128）分片下载；直链过期（403 / 404 / 410）时自动重新取链继续一次，也可手动「重新获取直链并继续」——分享、我的网盘、短视频 / 图集的下载都支持
- **登录后下载（光鸭）**：分享者关闭免登录下载时，登录光鸭后自动临时转存到个人盘取链，下载完成后清理
- **转存到我的网盘**：夸克、UC、百度、迅雷、115、123、139、光鸭、蓝奏云优享版登录后可把分享里的文件 / 文件夹（单个、多选或整个目录）转存到自己网盘，可逐级选择目标文件夹
- **下载设置**：全局限速、失败重试次数、按平台单独设置连接数、免转存下载开关、完成后移动到「文件」App 中任意文件夹（如 iCloud 云盘）、导出诊断日志
- **在线预览**：视频 / 音频在线播放（逐请求带 Referer / Cookie），图片缩放查看，文本文件在线查看，下载完成的文件用 QuickLook 打开；整个文件夹 / 一组图片在下载页收成可折叠分组
- **我的网盘**：登录后在「我的」页点网盘卡片进入自己的网盘：逐级浏览、下载、新建文件夹、重命名、移动、删除、创建分享并复制链接（可选永久 / 1 / 7 / 30 天有效，115 为永久 / 1 / 3 / 7 / 15 天）、上传文件或相册里的照片视频（能秒传的直接秒传，带进度、可取消重试）、查看容量（各平台支持的操作略有不同）
- **多账号**：同一网盘可登录多个账号，随时切换主账号；开启「多账号下载」后批量下载按文件轮换账号取链，分摊单账号的并发与限速
- **GitHub**：粘贴仓库 / 用户主页 / Release / raw 链接即可浏览目录、查看 Releases 并下载附件；可填 Token 提升接口限额、访问私有仓库（私有仓库的 Release 附件也能下载），可选公共下载镜像或自填前缀
- **中文口令**：迅雷中文口令直接向迅雷解析
- **实时活动**：下载进度显示在锁屏与灵动岛；多账号时可开启「单文件多源分片」，用多个账号的直链同时下载同一个大文件
- **文件管理**：下载文件出现在「文件」App →「我的 iPhone」→ Cloudn，可分享、存入相册
- **账号**：网页登录（独立的 WKWebView 会话，自动识别登录完成，Cookie 或网页本地存储里的令牌都能读取）、应用内账号密码 / 短信验证码登录（光鸭、迅雷、123、蓝奏云、蓝奏云优享版）或手动粘贴凭据；凭证只存钥匙串，可用口令加密导出 / 导入备份
- **外观与更新**：浅色 / 深色 / 跟随系统，自定义主题色，平台图标线性 / 实心可选；从 GitHub Releases 检查新版本（每天自动一次，可接受预发布版、可忽略某个版本）
- **分享扩展**：在 Safari、微信等应用里「分享 → Cloudn」直接唤起解析
- **磁力 / BT 下载**：粘贴磁力链接或打开 .torrent 文件，经 DHT 与 Tracker 找节点、取种子信息，勾选要下载的文件；逐块 SHA1 校验、断点续传，只下载不上传（应用在前台时下载）
- **检查更新**：新版本可直接从 GitHub（可走镜像）下载 IPA；发布说明里附了网盘链接时，「网盘下载」自动在分享里找到安装包并下载，做不到时打开分享页
- **收藏与历史**：常用分享一键打开，长按主屏幕图标可「粘贴并解析」或直接打开最近收藏；`cloudn://resolve?text=<链接>` 可从快捷指令等外部唤起解析

除各网盘 / 视频平台与 GitHub 自身的接口外，Cloudn 不依赖任何第三方服务。

暂不支持：微信视频号、小黑盒（只能借助第三方服务取数据，出于隐私不接入）、YouTube / Facebook / Snapchat（依赖 yt-dlp，无法在 iOS 上运行）。

## 构建

要求：Xcode 16 及以上，iOS 17 及以上。

```bash
git clone https://github.com/mengangs/Cloudn.git
open Cloudn/Cloudn.xcodeproj
```

在 Xcode 中选择自己的开发者团队（Signing & Capabilities）后运行即可。

每次推送 CI 都会构建一个**未签名的 IPA**（Actions → 最近一次运行 → Artifacts → `Cloudn-unsigned-ipa`），可用 AltStore / Sideloadly 等工具自签安装。

## 项目结构

```
Cloudn.xcodeproj        Xcode 工程（同步文件夹，新增文件无需手动加入工程）
CloudnShare/            分享扩展（把链接交给主应用）
Cloudn/                 SwiftUI 应用
  App/                  入口与全局状态（AppModel）
  Services/             钥匙串账号、设置、收藏、下载状态、隐藏 WebView、AVFoundation 合轨
  Views/                解析 / 下载 / 我的 三个标签页；Components/Theme.swift 为设计令牌与基础组件
  Assets.xcassets/      Icons（界面图标）、Platforms（线性平台图标）、PlatformsSolid（实心平台图标）
  Resources/Fonts/      思源宋体子集（标题衬线字体）
CloudnWidget/           实时活动（锁屏与灵动岛下载进度）
design/                 应用图标与实心平台图标的生成脚本
CloudnKit/              与界面无关的核心 Swift Package（可在 Linux 上编译与测试）
  Share/                链接识别与各网盘解析（夸克 / UC / 百度 / 迅雷 / 115 / 123 / 139 / 光鸭 / 蓝奏云 / 蓝奏云优享版）
  Support/              HTTP、动态 JSON、纯 Swift 摘要与 AES / RSA（各网盘签名参数用，Linux 上同样可测）
  Video/                抖音 / 快手 / 微博 / AcFun / 哔哩哔哩解析
  Download/             分片下载引擎、HLS、断点续传
  Tests/                单元测试 + 本地测试服务器（Range / HLS / 模拟夸克接口）
```

运行核心测试：

```bash
cd CloudnKit
python3 Tests/Server/test_server.py 8765 &
CLOUDN_TEST_SERVER=http://127.0.0.1:8765 swift test
```
